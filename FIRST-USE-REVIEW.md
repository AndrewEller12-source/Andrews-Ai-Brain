# First-use review — 0.11.1

The most valuable next improvement is a clear answer to “what needs me, and what happens next?” A large map earns attention, but clear questions, trustworthy progress and useful results earn repeat use.

## Fixed in this release

- Send now is available directly on waiting inbox rows.
- Questions remain discoverable across universe boundaries. The banner opens All Codex so the owner can answer the exact pending form.
- Branches show live agents and review counts together. Losing the dashboard connection stops live indicators.
- Universe setup uses neutral examples. Generic business names and revenue targets wait for actual subject matter before importing history. Matching requires stronger evidence and does not use internal review tasks as candidates.
- Delete and restore universes without deleting chats, files or running requests.
- Internal review completions are filtered from the result feed alongside Rewster voice turns.

## Highest-priority follow-ups

1. **A compact next-action home screen.** Put unanswered questions first, blocked work second, and deliverables ready for owner review third. Keep the universe as an optional live view. The current map and 20 mixed attention items require too much interpretation.
2. **Readable task and project names.** Live review exposed titles beginning with injected context and project names like generated folder IDs. Preserve exact source identity in details, but show the actual owner request and editable project labels in navigation.
3. **Explain membership at the task.** Automatic matches currently explain themselves inside universe settings. Add one-click “Why is this here?” and “Move/exclude” to each task, plus a small suggested-import preview for a new business.
4. **A result acceptance workflow.** Separate “agent ended its turn” from “owner reviewed and accepted the output.” Show the primary artifact and a clear next step before secondary activity logs.
5. **Account usage and cost visibility.** Show how routing, discovery and automatic reviews consume the account budget. Users need controls for this before increasing background automation.

These are product recommendations from the current app walkthrough, not claims that other users have requested or validated them.

## Verification boundaries

Automated checks exercise structured questions, exact-turn steering and uncertain receipts, queue prioritization, completion filtering, universe membership, deletion/restoration and UI behavior. A Send now request remains subject to the hard worker ceiling and occupied task/folder protection. Plain conversational questions are still answered in their chat; only pending structured forms produce the answer inbox. Desktop question support depends on the connected compatible Codex owner. No real user's answer or running task was submitted, stopped or replayed during this review.
