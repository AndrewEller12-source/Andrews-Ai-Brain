# Ai Task Manager releases

Download the Mac app and editable source from [the latest release](https://github.com/AndrewEller12-source/Andrews-Ai-Brain/releases/latest).

The Mac app uses the latest release's `appcast.xml` for signed in-app updates. Release ZIPs contain no account credentials or personal chats. Sign into your own Codex account after installing. Apple silicon, macOS 14 or later. The current developer build is not Apple-notarized.
